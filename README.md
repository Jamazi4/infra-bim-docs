# Infrastructure BIM: Self-Study Book

A self-study book on infrastructure BIM: ISO 19650 information management (including the CDE), bridges, roads, railways, geotechnics, drainage, utilities, tunnels and 4D construction modelling.

- **PDF:** `Infrastructure_BIM_Self-Study_Book.pdf`
- **Source:** `book/` ([Typst](https://typst.app))

Build:

```sh
typst compile book/main.typ Infrastructure_BIM_Self-Study_Book.pdf
```
